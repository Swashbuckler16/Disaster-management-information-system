## 🌟 Project Overview

## 🚀 How to Run the Working Prototype

### Option 1: Double-click `run_dmis.bat`
Simply double-click [`run_dmis.bat`] in the file explorer. It will start the server and automatically launch `http://localhost:8000` in your web browser.

### Option 2: Command Line (PowerShell / Terminal)
```bash
python server.py
```
Then navigate to: **`http://localhost:8000`** in your browser.
